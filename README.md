# Electricity-Billing-System
Java-based Electricity Billing System using OOP and Swing GUI for customer management, bill calculation, and billing record search.

## About the Project

This project is a Java-based Electricity Billing System developed using Object-Oriented Programming concepts.

The system allows users to enter customer details, electricity units consumed, and the rate per unit. It then calculates the total electricity bill and allows the user to search for a customer's bill using the account number.

The project uses a simple Java Swing GUI, making it easy to enter and view billing information.

## Features

- Add customer details
- Store customer account number
- Enter electricity units consumed
- Enter rate per unit
- Calculate total electricity bill
- Search customer billing details
- Display generated bill
- Simple graphical user interface
- Input validation
- Uses HashMap to store billing information

## Technologies Used

- Java
- Java Swing
- AWT
- Object-Oriented Programming
- HashMap

## Requirements

- Java JDK 8 or above
- NetBeans, Eclipse, or IntelliJ IDEA
- Windows or Linux
